This is a contact manager system for storing contact information. Contacts are stored by name and phone number. There is also a test file for running tests on the contact manager. Tests can run through the console or the file itself.

User input is taken to create a list of contacts. Options are given to add, search, and delete contacts.

Features:

Add a new contact to the list of contacts.

Search contacts by name for their phone number.

Delete a contact from the list of contacts.

Output:

A menu is given for user input options.

Status messages and results are printed.
